# بازرسی پل — Bridge Maintenance Android

سامانه آفلاین ثبت شناسنامه فنی، بازرسی چشمی پویا، مدیریت آسیب و گزارش‌گیری پل برای «شرکت مهندسین مشاور هگزا».

## هویت نسخه

- نام برنامه: `بازرسی پل`
- Application ID: `ir.bridge.maintenance`
- نسخه: `1.5.0` (`versionCode 10500`)
- حداقل Android: API 26
- رابط: فارسی، راست‌به‌چپ، آفلاین و بدون مجوز اینترنت
- پایگاه داده: SQLite محلی با رسانه‌های ذخیره‌شده در scoped storage

## قابلیت‌های اصلی

- «لیست پل‌ها» برای مشاهده، جستجو، افزودن، ویرایش، حذف دائمی و انتقال فایل مستقل پل.
- فرم شناسنامه ۲۰ بخشی و ۶۰ فیلدی که مستقیماً از فایل `reference/شناسنامه_فنی_پل_نشریه_367.xlsx` تولید شده است؛ سلول‌های دارای Data Validation در اکسل به منوی بازشو تبدیل شده‌اند.
- ثبت موقعیت پل با GPS دستگاه یا ورود دستی عرض/طول جغرافیایی.
- شروع بازدید با فیلد اول «انتخاب پل».
- تولید چک‌لیست پویا بر پایه کاربری، سیستم سازه‌ای، مصالح و اجزای پل؛ کنترل‌های مستقل برای راه، راه‌آهن، بتن، فولاد، پیش‌تنیدگی، بنایی، چوب، کامپوزیت، عرشه، تکیه‌گاه، درز، پی، آب‌شستگی و دیگر اجزا.
- مقیاس آسیب دقیقاً چهار سطح: `اضطراری`، `متوسط`، `کم`، `ندارد`؛ مقدار پیش‌فرض `ندارد` است.
- خروجی بومی PDF، XLSX، CSV و ZIP. بسته ZIP شامل هر سه گزارش، داده پل‌ها، داده بازدیدها، شِمای شناسنامه، فهرست مراجع، تصاویر و امضاهاست.
- نام‌گذاری عکس با کد/نام پل، بخش بازرسی و تاریخ بازدید.
- پشتیبان‌گیری کامل با SHA-256، بازیابی مرحله‌ای و تراکنشی و محافظت در برابر ZIP traversal.
- حفظ معنای رکوردهای چک‌لیست نسخهٔ ۱.۱ با شناسه‌های نسخه‌دار ۱.۲ و نمایش بدون تغییر موارد قدیمی در پیش‌نویس‌ها و خروجی‌ها.

فیلدهای قدیمی ناحیه راه‌آهن، ایستگاه‌ها، نوع خط/موقعیت، کیلومترها، جهت کیلومتراژ، سرعت، کلاس خط و آب‌وهوا در مدل جدید وجود ندارند.

## ساخت و آزمون

```bash
node --test tests/js/*.test.js
python3 tools/check_bridge_source.py
./gradlew testDebugUnitTest lintRelease assembleDebugAndroidTest assembleRelease
```

در محیطی که دسترسی دانلود Gradle/Android SDK ندارد، workflow با نام **Bridge Maintenance Build and QA** در GitHub Actions همان آزمون‌ها را اجرا و APK بدون امضا و ZIP سورس آزموده‌شده را تولید می‌کند.

## امضای انتشار

کلید خصوصی و رمزها در مخزن نگهداری نمی‌شوند. برای ساخت امضاشده این propertyها را بیرون از مخزن به Gradle بدهید:

```properties
BRIDGE_STORE_FILE=/absolute/path/bridge-maintenance-release.jks
BRIDGE_STORE_PASSWORD=...
BRIDGE_KEY_ALIAS=bridge-maintenance
BRIDGE_KEY_PASSWORD=...
```

دستور نمونه:

```bash
./gradlew assembleRelease \
  -PBRIDGE_STORE_FILE=/absolute/path/bridge-maintenance-release.jks \
  -PBRIDGE_STORE_PASSWORD='...' \
  -PBRIDGE_KEY_ALIAS='bridge-maintenance' \
  -PBRIDGE_KEY_PASSWORD='...'
```

جزئیات معماری، داده، مراجع و تحویل در پوشه `docs/` قرار دارد.
