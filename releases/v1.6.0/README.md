## ارتقا

۱. در نسخه فعلی از داخل برنامه پشتیبان کامل ZIP بگیرید و آن را خارج از پوشه برنامه نگه دارید.
۲. APK جدید را روی نسخهٔ موجود نصب کنید؛ نسخهٔ قدیمی را حذف نکنید و داده را پاک نکنید.
۳. پس از نصب، نمایش نسخه ۱.۶.۰، فهرست پل‌ها، بازدیدهای قبلی و عکس‌ها را کنترل کنید.
۴. با یک پل آزمایشی، پیش‌نویس، دوربین/GPS و خروجی گزارش را روی گوشی مقصد امتحان کنید.

سورس اجرایی در ریشه مخزن قرار دارد. ZIP سورس کامل هنگام انتشار از commit برچسب نسخه ساخته می‌شود؛ APK و ZIP نصب داخل ZIP سورس تکرار نمی‌شوند. فایل SHA256SUMS در Release شامل ZIP سورس تولیدشده هم هست و دامنه آن با فایل همنام این پوشه متفاوت است.
