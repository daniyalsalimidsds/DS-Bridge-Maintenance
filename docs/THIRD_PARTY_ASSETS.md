# دارایی‌ها و مجوزها

رابط برنامه از عکس، نقشه یا داده آنلاین ثالث استفاده نمی‌کند. نشان پل یک SVG اختصاصی همین مخزن است.

تصویر `veresk_loading.jpg` یک تصویر اختصاصیِ تولیدشده برای همین پروژه با الهام از نمای پل ورسک است؛ عکس ثالث یا محتوای دریافت‌شده از اینترنت نیست.

فونت‌های محلی:

- Noto Sans Arabic — SIL Open Font License 1.1
- Noto Naskh Arabic — SIL Open Font License 1.1
- Vazirmatn — SIL Open Font License 1.1

اعلان‌های حق مؤلف از metadata خود فایل‌های فونت استخراج شده‌اند. متن کامل مجوز فونت‌ها و Apache 2.0 همراه APK در `app/src/main/assets/licenses/` قرار دارد. نام شرکت‌ها صرفاً انتساب وابستگی است و به معنی تأیید مهندسی نرم‌افزار توسط آن‌ها نیست.

کتابخانه‌های AndroidX تحت Apache License 2.0 توزیع می‌شوند. فایل اکسل شناسنامه و اسناد ایرانی، منابع پروژه/سازمان هستند و وضعیت انتشار بیرونی آن‌ها باید توسط مالک پروژه تعیین شود.
