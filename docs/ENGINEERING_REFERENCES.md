## منابع پیشین کاتالوگ

چک‌لیست‌ها برای بازرسی چشمی طبقه‌بندی شده‌اند و از این منابع استفاده می‌کنند:

1. نشریه ۳۶۷، شناسنامه فنی پل‌ها — فایل اکسل و PDF مرجع ارائه‌شده برای پروژه.
2. راهنمای بازرسی چشمی پل‌های شهری، سند ۱۲۲-۳-۷ — فایل مرجع ارائه‌شده برای پروژه.
3. دستورالعمل بازدید پل — فایل مرجع ارائه‌شده برای پروژه.
4. FHWA, Bridge Inspector’s Reference Manual (BIRM), 2023.
5. 23 CFR Part 650, Subpart C — National Bridge Inspection Standards.
6. 49 CFR Part 237 — Railroad Bridge Safety Standards.
7. 49 CFR Part 213 — Track Safety Standards، به‌ویژه الزامات هندسه، سازه خط و بازرسی.

## مرز کاربرد

فهرست جامع به معنای تضمین کشف همه خرابی‌ها نیست. بازرسی چشمی محدودیت دسترسی، پوشیدگی عضو، شرایط نور/آب، خطای انسانی و خرابی داخلی دارد. برنامه جایگزین مهندس واجدصلاحیت، NDT، غواصی، دسترسی ویژه، تحلیل سازه، ارزیابی باربری یا دستور مالک پل نیست. شدت و اقدام باید مطابق روش مصوب سازمان و شرایط واقعی تعیین شود.
