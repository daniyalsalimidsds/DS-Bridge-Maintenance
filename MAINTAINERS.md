## Governance status

Bridge Maintenance is currently a single-maintainer open-source project. Maintainer roles may be expanded when sustained contributors emerge.

Technical changes can be proposed through GitHub Issues and Pull Requests. Changes affecting engineering interpretation, scoring, safety controls, data migration, or release integrity require explicit review and supporting evidence.

This file describes project governance only; it does not claim external adoption, institutional endorsement, or deployment.
